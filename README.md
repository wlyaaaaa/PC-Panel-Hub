# PC Panel Hub

- **这是什么：**机箱小屏显示电脑状态；水冷曲面屏显示时钟、音乐、游戏和重要提醒。
- **我怎么用：**开机后自动运行，平时不用管；屏幕没显示时，可以双击 `start-side-screen.cmd` 手动启动。
- **怎么知道正常：**看机箱屏的时钟是否每秒跳动、内容是否更新；曲面屏应显示当前有用的信息。
- **坏了怎么提醒我：**没有自动提醒，出问题直接跟 AI 说。
- **让 AI 做什么：**请 AI 检查两块屏的状态和日志，按故障范围修复，并在实体屏上确认结果。

安装、修复和配置见 [启动与恢复](docs/startup.md)；曲面屏功能见 [曲面屏说明](docs/hs2-crystal-overlay.md)。
